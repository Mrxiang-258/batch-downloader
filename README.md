# 本地批量下载器

一个运行在本机、带图形界面的批量下载器。输入网页 URL 或一批下载链接，选择保存目录，即可自动并发下载。支持断点续传、失败重试、暂停/恢复、任务持久化、网页链接解析等。

纯本地运行，不依赖云服务器，不调用任何付费 API。

## 一、项目文件在哪里

项目根目录：`F:\hermes workspace\downloader`


- `data/tasks.db` SQLite 任务数据库
- `config.json` 配置

## 二、如何首次启动

1. 双击 `start.bat`。
2. 首次运行会自动创建虚拟环境并安装依赖（需要本机已装 Python 3.10+，稍等片刻）。
3. 启动后浏览器会自动打开 `http://127.0.0.1:8000`。

停止：直接按 `Ctrl+C` / 关闭启动窗口，或双击 `stop.bat`。

> 已用 Python 3.12 在 Windows 11 上实测通过。若换机器，确保系统有 `py` 或 `python` 可用即可。

## 三、如何输入单个或批量链接

- **单个/批量粘贴**：把链接粘贴到顶部文本框，每行一个（支持 http/https 直链），点「添加下载」。
- **导入 TXT/CSV**：点「导入 TXT/CSV」，选择文件；文件里每行一个 URL，CSV 会自动取每行第一个字段。
- **解析网页**：粘贴网页地址（每行一个），点「解析网页」，会列出页面中可下载的文件链接，勾选后「加入下载队列」。

区分两种流程：普通网页地址 ≠ 文件直链。直链直接下载；网页地址走「解析网页」提取链接。需要登录、JS 渲染、动态令牌的页面会明确提示无法提取/下载。

## 四、如何指定下载目录

- 顶部「保存目录」输入框：为**本批任务**指定目录，留空则用默认目录。
- 默认目录：点右上角「⚙ 设置」→「默认下载目录」→「选择…」可弹出 Windows 原生文件夹选择器；也可以直接粘贴路径。
- 点「打开」可在资源管理器中打开当前目录。
- 支持按文件类型 / 来源网站 / 批次自动建子目录（设置里的「分类保存」）。
- 重名文件默认自动重命名（`x.txt` → `x (1).txt`），可在设置里改为「覆盖」或「跳过」。

## 五、如何管理大量任务

- 支持数千条任务导入与排队，导入为单事务批量写入，不会卡界面。
- 表格顶部可**筛选**（全部/等待/下载中/完成/失败/暂停/跳过/取消）、**搜索**文件名或 URL。
- 每行有 暂停/继续/取消/重试/打开/目录 按钮；勾选多行可批量操作。
- 工具栏提供：暂停全部、继续全部、重试失败、清空已完成、删除选中。
- 并发数（全局 + 单域名）、超时、最大重试次数在「设置」里配置；对 429/5xx/超时自动指数退避重试。

## 六、如何恢复中断的下载

- **断点续传**：服务器支持 Range 时自动续传（正确处理 ETag / Last-Modified / Content-Length / Content-Range），下载先写 `.taskN.part` 临时文件，成功后原子提交为最终文件。
- **应用重启后**：任务队列和进度都存 SQLite；上次下载中的任务会自动转为「已暂停」，点「继续」即从断点续传。
- 服务器不支持续传时自动回退为重新下载（不报错、不伪造成功）。
- 不完整的文件绝不会被标记为「已完成」，会明确显示失败原因。

## 七、如何查看日志和排查问题

- 服务日志直接打印在 `start.bat` 的窗口里（uvicorn 访问日志）。
- 每个失败任务在界面「状态」列下方会显示具体失败原因（HTTP 状态码、网络错误、大小校验失败等），可在「失败」筛选中集中查看。
- 任务数据库在 `data/tasks.db`，可用任意 SQLite 工具查看。
- 配置文件 `config.json` 损坏时会自动回退默认值，不影响启动。

## 八、运行自动化测试

```bash
cd /d F:\hermes workspace\downloader
.venv\Scripts\python.exe -m pytest tests/ -q
```

覆盖：单文件/批量下载、网页解析、重名处理、暂停与恢复、断点续传、服务器不支持续传的回退、网络超时与失败重试、无效/恶意 URL 拦截、重启恢复、数千任务导入。

## 安全说明

- 服务仅监听 `127.0.0.1`，不对外网开放。
- 下载与网页解析均做 SSRF 防护：拦截 localhost、内网 IP、云元数据地址等非公开目标，重定向后的每一跳也重新校验。
- 文件名与保存路径严格清洗，杜绝目录穿越，文件只能落到授权目录内。
- 日志不记录密码 / Cookie / Token；不自动执行下载到的文件。
- 默认遵守网站限制：并发受控、按域名限流、指数退避，不绕过访问控制或反爬。
- 如需下载局域网内资源（如 NAS），可在 `config.json` 中把 `allow_private_network` 设为 `true`（仅用于你明确授权的内网资源）。
